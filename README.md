This is a very basic game where you play as a little guy in a dark forest, trying to collect embers to keep the campfire alive. The environment is very dark, which was done to making things more challenging. The campfire dies over time, only collecting embers will keep the fire alive. However, the embers disappear if you don't collect them, so act fast!

This game was made in Unity, and it is playable through the link under "About"! It is still a work in progress, more features will be added! It is my first time trying out Unity, so things are a little bit messy and the game probably has many flaws, but hopefully you enjoy it!
